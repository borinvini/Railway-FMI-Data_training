# Feature selection per training scenario — one column name per line.
#
# Template for config/scenarios.txt (gitignored working copy): copy it there,
# edit that, then run hpc/push-features.sh config/scenarios.txt to upload it
# to Roihu. No commit is needed. Derived from scenarios_catalogue.txt.
# Blank lines and # comments are ignored. Names are taken verbatim, so do
# not quote them or add commas: Air temperature (12h max) is a valid line.
#
# This file holds all thirteen scenarios, in catalogue order, so --scenario <n>
# selects scenario <n>.
#
# Careful when editing these comments: a line starting with "# <n> -"
# is parsed as a scenario banner, so do not write ranges that way.
#
# trainDisrupted is the target and must stay: the trainers split it out of
# the feature matrix by name. trainDelayed and cancelled are dropped at stage 502.
# trainNumber is a join key (with departureDate it identifies one run), not a feature:
# stage 502 drops it even though it is listed here.
